#+title: organ

[[https://intver.org/][https://img.shields.io/badge/versioning-intver.org-blue.svg?style=for-the-badge]]

A Clojure library to parse [[https://orgmode.org][Org mode]] text into an AST (EDN data).

* Usage

#+begin_src clojure
(require '[bzg.organ :as organ])

(organ/parse-org "* Hello\nSome *bold* text")
;; => {:type :document, :title "Untitled Document",
;;     :todo-keywords {:todo ["TODO"], :done ["DONE"]}, :children [...]}

(organ/format-ast-as-edn (organ/parse-org (slurp "notes.org")))
#+end_src

Text fields keep raw Org markup; rendering is left to consumers (see
[[https://github.com/bzg/hop][hop]]).

The preamble (=#+KEY: value= lines before the first content line) is
exposed as =:meta=, an array map in file order keyed by lower-cased
keywords; a repeated keyword holds a vector. A =#+KEY: value= line later
in the body becomes a ={:type :keyword :key "todo" :value "..."}= node.
Both can be re-emitted verbatim.

TODO keywords default to =TODO= and =DONE=. =#+TODO:=, =#+SEQ_TODO:= and
=#+TYP_TODO:= directives replace this set for the whole file, as in Org.
Keywords from your Emacs configuration extend it with =:todo-keywords=:

#+begin_src clojure
(organ/parse-org org-string {:todo-keywords "NEXT STRT WAIT | CANX"})
;; or {:todo-keywords {:todo ["NEXT"] :done ["CANX"]}}
#+end_src

The effective set is the document's =:todo-keywords=; =parse-todo-keywords=
reads the directive set from raw Org text.

Ordered lists ignore the number written in a bullet, as in Org. An item
starting with =[@5]= or =[@start:5]= carries =:counter 5=, for
=<li value="5">= (=[@c]= gives 3). Single-letter bullets (=a.=, =B)=) need the
=:alphabetical-lists?= option, like Org's =org-list-allow-alphabetical=;
such lists carry =:alphabetical= (=:lower= or =:upper=):

#+begin_src clojure
(organ/parse-org "a. First\nb. Second" {:alphabetical-lists? true})
#+end_src

Filter and clean:

#+begin_src clojure
(-> (organ/parse-org org-string)
    (organ/filter-ast {:level-limit 2 :title-pattern #"TODO"})
    organ/clean-node)
#+end_src

Extract plain text from inline nodes:

#+begin_src clojure
(organ/inline-text (organ/parse-inline "See [[https://x.com][Example]]"))
;; => "See Example"
#+end_src

A link without description contributes its URL. Use =:bare-link= to
drop it (=:omit=) or decide link by link:

#+begin_src clojure
(organ/inline-text nodes {:bare-link #(when-not (image-url? (:url %)) (:url %))})
#+end_src

* Install

As a Clojure CLI dependency:

#+begin_src clojure
org.clojars.bzg/organ {:mvn/version "3.4.0"}
#+end_src

Works with both Clojure and [[https://babashka.org][Babashka]] (no external deps).

* Test

: ~$ bb test

* Deploy

With =CLOJARS_USERNAME= and =CLOJARS_PASSWORD= set:

: clj -T:build deploy   # or install (local), or jar (build only)

The version is set in =build.clj=.

* Intentional Versioning

This project uses [[https://intver.org][Intentional Versioning]], here are the three audiences:

- =Users= : people using software built on organ (e.g. [[https://github.com/bzg/hop][hop]]); organ itself has no end-user surface
- =Integrators= : API consumers, i.e. maintainers who rely on organ for their code (the AST is the API)
- =Maintainers= : maintainers of the codebase
